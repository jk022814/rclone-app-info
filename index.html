John Homelab rclone

This is the information website for a personal-use Google OAuth client used with rclone to manage the owner's Google Drive backups.

The client is intended for the owner's own backup workflow, not a service offered to the public. Google authorization allows rclone, running on owner-controlled systems, to access Drive files within the permissions the owner grants.

This static website does not perform Google sign-in, receive OAuth tokens, or host backup contents. Do not upload credentials, authorization JSON, or backup files to this website or its public repository.

Privacy policy

For non-sensitive questions about this application, use the project's public issue tracker. Never include credentials or private backup information in an issue.

Personal application information. This application is not operated by or endorsed by Google or the rclone project.
